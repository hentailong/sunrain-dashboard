# 今天是太阳雨 · 数据看板

React / TypeScript / ECharts / FastAPI / SQLite 本机数据台。云合每30分钟采集，灯塔、酷云每分钟检查，其余已实现的来源每15分钟检查；页面每60秒检查新数据。各平台独立执行，电脑休眠或关机期间不补造数据。

## 单剧看板

首页参考 https://jiuchu.github.io/jjc/ 的深色金色视觉与单剧分区结构，展示《今天是太阳雨》的剧集进度、核心指标、酷云直播收视及播放、热度、讨论趋势。页面不再提供双剧对比与小红书入口，历史数据库保留原有记录。

微博合为一张卡，展示阅读、讨论与官微粉丝；豆瓣合为评分、短评与长评卡。云合有效播放市占和全舆情热度分别附上对应排名，日期不一致时单独标注排名日期。灯塔展示播放量、市占率和播放排名。

灯塔固定按实际采集分钟落点，提示中单独保留来源更新时间，避免平台时间未变化时覆盖连续采样。酷云只在湖南卫视节目单准确匹配本剧且数据新鲜时记录收视；首播前显示待播，停播或失败时不冒充实时值。湖南卫视官方公告为2026年11月11日20:10起首播，后续采集依赖实时节目单，不假设每天固定时段。

## 启动

需要 Python 3.12、Node.js 18+。Windows PowerShell 中运行：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\start.ps1
```

脚本安装 Python 依赖及 Chromium，并启动后端和前端。访问 http://127.0.0.1:5173 ，后台服务保持运行才能持续采集。默认仅监听本机。

## GitHub 部署

项目已包含 `.github/workflows/pages.yml` 和 `.github/workflows/refresh-remote-api.yml`。Pages 负责发布前端，常驻 FastAPI 后端负责灯塔、酷云每分钟采集，Actions 每15分钟触发其它来源刷新。GitHub Actions 不能保证实时调度，不能单独承担灯塔和酷云采集。完整配置见 [docs/github-deployment.md](docs/github-deployment.md)。

## 自动数据源与已验证状态

- 芒果TV：核对本剧详情头部的播放图标与结构化 `detail.playCnt` 字段，采集累计播放官网展示值（按万／亿取整，非精确到次）。首页展示播放量卡片，平台详情只画播放趋势，集数保留为最新读数。旧版未确认口径的页面数值保留归档，不混入播放曲线。
- 微博：后台直接请求官方移动接口，缓存并复用本机会话。首次初始化或会话失效时仅使用无界面浏览器建立会话，不打开可见标签。自动记录话题累计阅读量、累计讨论量、官微粉丝数和微博数。“万／亿”保留官网展示精度，不假装精确计数。
- 豆瓣：已验证本剧公开剧集页，记录评分、短评、剧评、在看、看过、想看等实际可读字段。未开分时保留空值并显示“暂无评分”，不读取推荐剧评分。
- 抖音：仅统计官方“剧集榜 → 实时榜”的热度和排名。已从PC搜索“剧集榜”的官方卡片定位榜单入口，验证其公开GET接口 `/web/api/ent/billboard/info/`，使用 `chart_key=entertainment_teleplay_v2`、`billboard_type=2`。热度读取原始 `score`，排名读取明确的 `item_info.rank`，统计时间取 `active_time`。后台每15分钟请求一次，同一份榜单同时更新两部剧，不打开浏览器、不需要保持登录窗口。数值链接打开当次榜单字段摘录，包含官方接口地址，便于核对；官网卡片按万／亿显示的值可能四舍五入。旧搜索视频点赞、评论、分享历史保留在库内归档，从当前指标、对比、趋势和预测中排除，不与榜单数据拼接。
- 猫眼：已验证公开榜单，自动读取排名与近日热度趋势。趋势值不等同于字体编码的实时热度，不用柱形长度估算。
- 云合：优先请求小程序官方 POST 接口；会话令牌过期或接口返回 5xx 时，自动切换到官网公开 GET 榜单接口，不再依赖小程序令牌。后台每30分钟采集最新长剧日榜，分别记录热播榜排名、正片有效播放市场占有率、全舆情热度、全舆情榜排名。全舆情排名按接口返回的榜单序位计算，并校验热度降序。两个榜单统计日期分别来自各自响应，不用采集时间冒充榜单日期。
- 百度指数：使用项目独立的无界面 Chromium，每15分钟读取指定关键词趋势页的搜索指数图。口径为全国 PC+移动，按实际统计日存档；品牌、资讯指数不混入搜索指数。
- 灯塔：已从官方 Android 8.3.2 安装包定位“网播/收视”的官方 H5 页面，验证 v3.0 网播榜接口。后台每分钟检查正片播放量、市占率和排名，同一榜单同时更新两部剧，无需企业认证、手机连接或浏览器登录。分别保存平台更新时间与采集时间，跨日重新统计并断开趋势连线，不与云合有效播放混用。电视收视和集均播放尚未接入。静态分析及接口口径见 docs/dengta-data-access.md。
- 酷云：直连官方 `/api/rtepg`，每分钟核对湖南卫视（频道24）的节目、起止时间与更新时间。只存本剧实际收视率和市占率，比例乘100转百分数。不同节目段分开画线，不填停播期间的零值；接口或时间异常保留历史。

来源页展示最后尝试、最后成功、实际下次任务时间、错误及自动重试入口。采集失败保留上次成功值和采集时间。每条数值及可用图表数据点提供来源链接。云合 POST 请求不能通过地址栏重放，因此数值链接打开本机保存的当次官方原始 JSON 响应，内含官方接口地址、无凭据参数、采集时间及原始数据。

## 云合本机会话

当前机器已连接两个请求。重新连接时可从小程序的本人正常网络请求保存抓包文件，再运行：

```powershell
python scripts\connect_yunhe.py 'C:\path\热播榜请求.txt' 'C:\path\全舆情榜请求.txt'
```

脚本仅提取请求配置及会话，不导入抓包响应中的统计数据。会话保存在 backend/local-secrets/ ，不会通过接口或证据页暴露。会话失效时显示具体状态，重新连接后恢复自动请求。不要分享该目录或原抓包文件。

浏览器登录与访问验证会话保存在 backend/browser-profiles/ 。密码仅在官方页面输入，不经过本平台。这些目录、数据库、原始响应均已加入忽略列表。

## 分析与预测

全景看板仅保留正片播放、酷云收视、云合有效播放市占、猫眼热度与百度指数曲线；其他指标只在上方卡片展示。图表按播放与热度分组，首页不显示时间或平台筛选，直接展示全部保留的图表。云合有效播放市占读取已存档的全部统计日期；其他图表固定展示今天。灯塔改为完整小时播放量蓝柱、今日小时市占金线、昨日小时虚线；昨日未存档时不伪造对比。空值不补零，灯塔每分钟检查并保留完整小时分时值，其他实时平台按15分钟对齐；酷云按分钟与节目播出时段分段。每张图显示区间读数、峰值和变化。

灯塔详情筛选为“今日 / 全部”：今日显示分钟采样，全部通过官方逐日接口读取历史正片播放量和市占率，使用 vvCnt 而非累计 totalVv；当日数据尚未结束，持续修订。酷云详情也使用“今日 / 全部”，全部展示所有已存档播出时段，按节目与采集缺口断线，不生成停播数据。

平台详情、趋势预测与数据来源通过顶部导航进入。最新读数与历史曲线分别标明统计时间，不用采集时间冒充日榜日期。

预测按小时或日进行分桶，24小时预测需要7天小时历史，7天预测需要28天日历史，覆盖率至少80%。高频重复采集不能代替足够的历史跨度，日榜不能用于小时预测。朴素基线与阻尼趋势通过按时间顺序的滚动回测比较绝对误差，选择误差较小的模型；估计区间来自回测绝对误差分位。样本不足、数据过期、排名指标均暂停预测。

猫眼每15分钟保留官网当日趋势展示值的采集快照，按实际采集时刻落点，跨统计日断线；它不等同于实时热度。详情图表只保留热度，筛选为“今日 / 全部”，不再单列排名图和日趋势图。“今日”显示当日采集快照，“全部”每个日期显示一条数据，历史日期优先采用官网日值的最后一次修订，缺失日期及当日使用最后一次有效快照。旧记录只恢复当时实际保存的同日采集点，停机或旧版去重造成的缺口不补造。

## 数据库备份

先停止后端，再复制 backend/data.db。若要同时保留云合原始来源证据，复制 backend/evidence/。恢复时将文件放回原目录。凭据和浏览器会话与统计数据分开保存；迁移本机采集时需自行妥善保管，不能公开提交。

## 接口

- GET /api/compare 全平台双剧指标、可比性、差值和来源
- GET /api/overview 总览（支持 title=折月亮）
- GET /api/sources 来源状态、实际周期、下次运行及指标
- GET /api/series?source=weibo&hours=168 历史序列（云合、猫眼、灯塔、酷云支持 all_history=true）
- GET /api/dengta/daily 灯塔官方全部逐日播放、市占与历史更新状态
- GET /api/forecast?source=weibo&metric=topic_discussions&hours=24 预测
- POST /api/refresh 全部采集
- POST /api/sources/{source}/login 打开官方登录／验证窗口
- POST /api/sources/{source}/refresh 采集一个来源
- GET /api/evidence/{filename} 云合当次官方响应／抖音当次榜单字段摘录
- GET /api/health 健康检查

旧 /api/import 仅保留兼容，网页不提供导入入口，自动采集不依赖手动数据导入。

## 百度关键词搜索指数与展示更新（2026-11-11）

百度采集使用项目独立的无界面 Chromium，会话保存在 `backend/browser-profiles/baidu_index/`，只读取 `/trend/今天是太阳雨` 下 `trendChart` 的全国、PC+移动日值；采集结束关闭独立浏览器。每15分钟检查，保留全部已存档日期，登录失效时保留上次正确读数并提示在项目独立窗口重新登录。无需日常 Chrome、浏览器调试端口或 CDP Proxy。官网 `trendChart2` 为资讯指数，不能混用。

此前错误接入的电视剧品牌搜索指数已经改名归档为 `baidu_brand_search_index_legacy`，证据与原始观测仍保留，不再进入当前卡片及图表。2026-11-11 验证关键词搜索指数最新日为 11 月 9 日，值 35,380。8.28万对应其他口径，不是该关键词日值。

首页里程碑使用全部已采集历史，排名取最小名次，热度与阅读量取最大值，记录相同时标记最近一次出现日期。图表默认提示保留两位小数，移除“最新统计日变化 / 区间变化”。顶部剧集介绍采用芒果 TV 官方海报、主演及简介，杨超越排在首位。

酷云首播倒计时采用官方北京时间首播时间，逐秒更新，归零后等待节目单确认，不将到点当作已开播。豆瓣评分仅保留卡片，不进入趋势指标下拉选项。

## 独立后台采集

依赖已安装时，运行 `./start-background.ps1`。脚本验证端口归属，避免重复启动本项目；以隐藏进程启动后端，日志写入 `backend/logs/`。无需打开前端页面，也不连接日常 Chrome。当前所有定时任务使用 HTTP 接口或项目专用的无界面 Chromium，保留原采集周期。

登录会话失效时，在看板“数据来源”中打开官方登录/验证窗口。该窗口使用项目独立目录；百度下一轮采集会关闭该窗口并转回无界面模式。不会复制或读取日常 Chrome 的个人配置。已验证已有独立百度会话可直接使用。

这是本机后台进程，不是开机自启服务；电脑关机、休眠或退出 Windows 登录后不能保证采集。重新登录后可再次运行启动脚本。关闭看板、终端或个人 Chrome 不影响已启动的隐藏后端。
