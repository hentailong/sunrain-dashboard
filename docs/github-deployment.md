# GitHub Pages 与 Actions 部署

页面由 `pages.yml` 构建，公开数据由 `collect.yml` 发布到 `data` 分支的 `snapshot.json`。页面每分钟读取该快照，正式版本隐藏趋势预测和数据来源。

## 更新频率

Actions 采集进程在每分钟 00 秒触发灯塔和酷云请求，数据返回后发布；其他来源每 15 分钟采集一次。每个进程运行最多 330 分钟，定时工作流串行衔接。GitHub 排队、任务重启、平台限流与网络故障都会造成间隔，这不是有每分钟可用性保证的服务。Pages 无法绕过灯塔和酷云接口的浏览器跨域限制。

## 历史与凭据

公开快照只包含主剧的指标、统计时间和展示所需元数据；不包含账号、Cookie、浏览器资料、原始数据库或取证文件。新 runner 从快照恢复历史，来源失败时保留已有数据。灯塔与酷云分钟记录公开保留最近三天；官方日数据继续保留全部日期。

百度指数等要求登录的平台在新 runner 上可能无法继续采集，页面会保留旧读数和实际统计日期。不会上传本机登录会话。

## 酷云口径

“今日”对齐本日实时采样与昨日官方分钟曲线，昨日使用虚线；“全部”使用官方日均收视。历史秒峰值与实时分钟采样峰值不同。官方昨日曲线每天同步，未发布时每 15 分钟重试。

## 播出计划

已核实的湖南卫视第二周官方日历包括 11 月 11 日第 1–2 集、12 日第 3–4 集、15 日第 5–6 集。20:10 是计划时间，实时是否在播以酷云节目核验为准，不推算未公布日期。

页面读取上一完整采集分钟对应的 `minute-0` 至 `minute-11` 轮转分支，并核对 `publication_minute`，以避开 GitHub 原始文件五分钟缓存。`data` 分支持续保存完整公开快照，用于恢复与失败回退。没有采集到的分钟不会标为已更新。

播出时间每 15 分钟从电视猫的本剧播期表同步，按湖南卫视具体集数和时间选择下一场；失败时保留最近一次核实的节目单，酷云确认本剧正在播出后显示“播放中”。

## 多日播放预测

参考最近 7 个自然日中具备完整 24 小时的日期；目前初始分时档案含 2026-11-11、2026-11-12。每个历史日分别计算今日最近最多 6 小时的同比比值与绝对差值，以 3 小时半衰期加权；剩余各小时采用比例法和差值法各 50%，再按历史日期的 3 天半衰期合并。今日实际播放量只计一次。至少需要今日连续 3 个完整小时，不完整历史日不参与。权重为启发式设定，尚未回测校准。

完整分时历史随公开快照持续保存；旧版快照丢失的历史仅以已采集档案补缺，绝不覆盖更新记录。图表仍只展示今日与昨日。
